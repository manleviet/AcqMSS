# Refactor cross_validation.py to Use fold_io

## Goal

Eliminate non-reproducible `_split_into_folds` (uses global `random.shuffle`) by delegating to `generate_folds` from `fold_io.py` (uses seeded `random.Random(seed)`). Make `seed: int` required (no default).

## Current State

- `_split_into_folds` at line 488 uses `random.shuffle` (global RNG state) -- non-reproducible
- `generate_folds` in `fold_io.py` uses `random.Random(seed)` -- fully reproducible
- Both CV functions have `seed: int = None` (optional)
- `shuffle_each_fold` also uses global `random.shuffle` -- secondary reproducibility issue

## Key Decisions

1. `seed` becomes required (`seed: int`, no default) in both CV functions
2. When `fold_data is None`: call `generate_folds` + `apply_folds` instead of `_split_into_folds`
3. `shuffle_each_fold` should also use local `random.Random(seed)` for full reproducibility
4. `_split_into_folds` removed entirely (no other callers)
5. No test files call CV functions directly -- only app callers need updating

## Risks

- `run_interactive_eval.py` currently passes `seed=None`; must ensure config provides a seed value or the app sets a default before calling CV

## Resolved Decisions

1. **`shuffle_each_fold`** → Yes, switch to seeded local RNG in this same refactor
2. **Shuffle seed source** → Use `fold_data.shuffle_seeds[fold_idx]` (from FoldData) when fold_data is available; this gives per-fold deterministic seeds generated by the original fold-generation seed
