KEY POINTS:
───────────

1. CREATION: FMOracleTaskPreparation loops through model.variables to create
   pos/neg assumption pairs for each feature.

2. STORAGE: Dicts stored in FMOracleModel → BGData → QuAcqTask (immutable copy)

3. PROPAGATION: Oracle.get_bg_data() → QuAcqTaskPreparation.prepare() → QuAcqTask

4. PARAMETERS: _learn_params_from_task() flattens QuAcqTask fields for QuAcq.learn()

5. CONSUMPTION: QuAcq._prune_rejecting_constraints() uses dicts to convert feature
   assignments to assumption IDs for SAT-based consistency checking.

6. OPTIONAL: Dicts default to None in QuAcq.learn(); fallback to legacy Boolean
   evaluation if unavailable.

7. DUAL USE: Also used in FMOracleModel._config_to_assumptions() for configuration
   application.
